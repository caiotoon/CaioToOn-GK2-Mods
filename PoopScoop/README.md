# Poop Scoop

Put the wrong fertilizer on a garden bed? Right-click it to scoop it back out. The fertilizer slot empties
and the fertilizer item goes back into your backpack. In the base game a fertilizer can only be swapped for
another, never taken off.

- Works only on an empty bed, before you plant. Once something is growing, or a gardener has an order on the
  bed, the fertilizer stays.
- You get back exactly what applying it used up. If your backpack is full, the rest drops at your feet.
- Controller: focus the fertilizer slot and press the button that moves items between chest and backpack
  (the game's `ItemMove` action).
- No settings.

## Install

Install `PoopScoop-<version>.zip` through Vortex, or drop `PoopScoop.dll` into
`<game>\BepInEx\plugins\PoopScoop\`.
